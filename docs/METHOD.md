# CellRoB 方法整理

CellRoB 从单细胞接触数据计算候选边界强度，并将不同细胞中邻近的候选边界对齐到共同位置。

## 1. 相似细胞加权补全

目标细胞的每条 contact 权重设为 1。程序读取预先计算的细胞相似度矩阵，尝试加入相似细胞的 contact，并以相似度作为权重。按染色体和离散化后的位置汇总权重，构建染色体内接触矩阵。

补全使用相似度行副本，排除自身及非有限相似度，每轮选择相似度最高的未选邻居。只加入相似度严格大于 0.05 的邻居，最多加入 impute_n 个不同邻居；原相似度矩阵保持不变。

## 2. 有效 bin 与绝缘分数

去除矩阵对角线并对称化，列和小于 1 的 bin 视为无效。在有效 bin 构成的压缩矩阵上计算分数；有效 bin 少于 100 时，返回全零结果。压缩后相邻位置可能跨越原始基因组的空白区。

对于位置 i，窗口长度为 w，源码计算：

- A：左侧窗口的上三角内部接触总和。
- B：右侧窗口的上三角内部接触总和。
- C：跨越位置 i 的左右接触总和。

当 A+B-C 大于 0，`IS[i] = (A+B-C)/(A+B+C)`；否则为 0。源码 C 的切片为 `mat[i-w:i, i+1:i+w]`，右侧只有 w-1 列；B 的右端切片可到 i+w。这里记录精确实现，不把它改写成对称的理想窗口公式。两端无法计算的位置保持零。

## 3. 候选边界评分

给 IS 添加小于 1e-6 的随机扰动以处理相等值。在左右最多 `floor(20,000,000/binsize)` 个有效 bin 范围内寻找更高分数位置，取最近距离 d；两侧均不存在更高分数时使用最大搜索距离。

定义 `eta = IS * (d-1)`。对 eta 降序排名，分别以最大排名和最大 eta 归一化，计算 `(normalized_eta + normalized_rank)/sqrt(2)`。取该值最小位置的 eta 为归一化基准，输出 `eta / baseline_eta`。最后将分数和 IS 填回原始 bin 坐标，无效位置置零。

这里的 `cluster` 表示连续边界评分。

## 4. 跨细胞对齐

按输入细胞顺序合并结果。先移除 IS 不高于该细胞染色体均值的位置，然后将边界分数不低于 `floor(40000/binsize)` 的位置转为候选边界。

对跨细胞候选边界计数，用长度 `2*floor(40000/binsize)+1` 的全一核做卷积，不进行平均归一化。使用负信号的峰值，即原信号的局部低谷，划分对齐区域。区域内候选边界总数必须严格大于 `count_threshold`。

对每个可能的锚点 s，损失为区域内所有候选边界位置 d 及携带该候选的细胞 c 的 `IS[c,d] - IS[c,s]` 之和。选择损失最小位置作为共同锚点。每个区域有候选边界的细胞，在锚点位置写入自身区域内的最大 IS；其他位置为零。

## 参数

| 参数 | 核心默认值 | 解释 |
| --- | --- | --- |
| binsize | 40000 bp | 接触离散化分辨率 |
| window | 5 bins | 有效 bin 压缩矩阵上的窗口 |
| impute_n | 15 | 最多加入的不同邻居数 |
| worker_n | 1 | 文件处理线程数 |
| count_threshold | 0 | 区域候选总数需严格超过此值 |

运行示例使用 40 kb、window=15、impute_n=15。window 的单位为有效 bin；可根据目标窗口跨度和分辨率配置，例如 `window=600000//binsize`。
